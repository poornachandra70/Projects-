# Personal Expense Tracker

A simple command-line Python application to manage and track your daily personal expenses.

## Features
- **Add Expense**: Record new expenses with name and amount.
- **View Expenses**: Display all logged expenses.
- **Total Expense**: Calculate and view total money spent.
- **Delete Expense**: Remove specific expense entries.

## How to Run
```bash
python "Project 1/src/Personal Expense Tracker.py"
```
